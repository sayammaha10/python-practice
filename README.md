# Python Practice Projects

A collection of Python projects I built while learning and practicing Python. This repository documents my learning journey through hands-on projects, covering Python fundamentals, problem-solving, file handling, object-oriented programming, and other core concepts.

---

## Projects

### 1. Quiz Game

A simple command-line quiz game built with Python that asks users a series of questions, checks their answers, and displays the final score as a percentage.

### 2. Number Guessing Game

A simple command-line number guessing game built with Python that generates a random number within a user-defined range and provides feedback until the correct number is guessed.

### 3. Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python that lets users play against the computer while keeping track of the total wins for both players.
